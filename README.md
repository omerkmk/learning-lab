# learning-lab

Hands-on iOS learning lab: small experiments and topic cards, one concept at a time.

Each topic is studied by hand before it is used in my main project, SubTrack (UIKit, MVVM-C).

## Structure

- `konular/<topic>/deney/`: the experiment code
- `konular/<topic>/kart.md`: the topic card (what, why, alternatives, where it is used, interview question)
- `KONULAR.md`: status of every topic and the date of its last review

Topic cards are written in Turkish.
